# ParkingAlot

Sistema de controle de estacionamentos.

## Stack

- Backend: Flask + SQLAlchemy ([`backend/`](backend/README.md))
- Frontend: Vue 3 + Vite + TypeScript ([`frontend/`](frontend/README.md))

## Requirements

- Python 3.12+
- Node.js 22.18+
